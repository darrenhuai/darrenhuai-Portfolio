Open source

In September 2026 I spent a few weeks fixing bugs in platformdirs and virtualenv, two libraries that most Python tooling depends on. Eleven of the fixes were merged. Each link goes to the pull request.

platformdirs (opens in a new tab) 6 merged

Finds the right user and system directories on each platform. pip ships a copy of it.

  • Accept use_site_for_root in the bin functions
  • Return one user path for root under multipath
  • Accept multipath in the site cache functions
  • Read user-dirs.dirs as shell assignments, not INI
  • Only create the site dirs a call hands back
  • Ignore relative XDG user directory environment variables

virtualenv (opens in a new tab) 5 merged

Creates isolated Python environments. tox, nox and pre-commit build theirs with it.

  • Replace a stale symlink instead of writing through it
  • Ignore a config file that fails to parse instead of crashing
  • Restore PKG_CONFIG_PATH that was not set before
  • Keep and restore the user's TCL_LIBRARY and TK_LIBRARY
  • Undo a live activation before activate.bat saves values

The user-dirs.dirs fix is a good example of the kind of thing I was after: the file is a shell fragment (opens in a new tab), but it was being parsed as an INI file, so duplicate keys crashed the parser and comments ended up inside paths.
