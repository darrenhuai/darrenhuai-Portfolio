GreetBot

A robot that recognizes a face and offers a handshake, built by a 14-person team in a UCLA engineering club.

Role
One of 14 team members.
Stack
Python, OpenCV, face_recognition (dlib), Arduino over Firmata
Links
Source for GreetBot (opens in a new tab) My fork of the team repository.

How it works

A camera feeds frames to a face-recognition module. It checks whether a frame contains a face, finds the largest one, and compares its encoding with encodings generated ahead of time from a folder of known faces. A runner script ties the recognition to the Arduino hardware that performs the greeting.

The face module

The recognition code was pulled out into a module with three functions, so other projects can reuse it.

from detector import has_face, find_face, generate_encodings

encodings, names = generate_encodings(directory)
if has_face(image):
    image, encoding, location = find_face(image)
